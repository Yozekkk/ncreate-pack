# Проверка внешних модов

`scripts/import-pack.py` ищет точный SHA-512 каждого активного JAR в официальном Modrinth API. Совпадение файла, размера и URL сохраняется в `external-sources.json`. Файлы без такого совпадения попадают в `UNRESOLVED.json`, и `prepare-release.mjs` блокирует выпуск.

Для файла вне Modrinth проверяйте официальный проект и конкретную версию, прямой HTTPS URL автора или его площадки, разрешённость использования в сборке и неизменность файла. В `sources/reviewed.json` ключом служит SHA-512 исходного файла; запись содержит provider, URL, SHA-256, size, страницу источника и, если есть, project/file ID. Импортер использует запись только при точном совпадении всех трёх хешей/размера с новым ZIP. В CI `verify-external-sources.mjs` скачивает каждый файл и повторно сверяет SHA-256 и размер до публикации канала.

Текущие 147 активных модов ссылаются на их исходные загрузки. 137 найдены по точному хешу Modrinth. Четыре FTB-мода загружаются из Maven FTB, пять файлов — из CurseForge CDN по идентификаторам опубликованных файлов, один Cataclysm — из встроенного в экспорт URL Modrinth CDN с проверенным SHA-256. Для Cataclysm Modrinth API больше не возвращает соответствующую версию; если CDN удалит файл, потребуется проверить актуальную официальную CurseForge версию и выпустить новый pack manifest. Никогда не заменяйте отсутствующий файл другим JAR без проверки совместимости и нового выпуска сборки.

Репозиторий не содержит сторонних JAR. В `packs/ncreate-server/1.0.2/files/` хранятся конфигурации и небольшой NCreate language resource pack. Адрес `play.ncreate.online:25076` извлечён из исходного `servers.dat` и опубликован как отдельное поле manifest; сам файл со списком серверов не копируется. ZIP игрока и его персональные данные не публикуются.
